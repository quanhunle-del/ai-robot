# 包子字幕横向滚动固件

固件：`baozi-five-wake-horizontal-idle-clean-full.bin`，完整合并镜像，8,772,904 字节。
适用：ESP32-S3 N16R8、ST7789 240×240、bread-compact-wifi-lcd 默认接线。
版本：用户提供的 XiaoZhi 2.5.2 源码，ESP-IDF v6.1，LVGL 9.5.0。

## 改动

- 待机时隐藏完整顶部状态栏（时间、状态文字、网络、电量等），唤醒后恢复。

- 底部字幕固定单行。长句左右往返滚动，速度约 60 像素/秒，开头及两端停留约 1 秒。
- 一行能完整显示时，文字静止居中。
- 消息中的 CR/LF 换行转为空格，防止出现纵向滚动；空消息隐藏字幕。
- 保留原固件的分区地址、字体、表情和五个包子唤醒词，资源区逐字节一致。

## 烧录

烧录地址必须为 **0x0**。这是完整固件，不能作为单独应用 OTA 文件上传。
选择 ESP32-S3、16 MB Flash、80 MHz、DIO（应用启动后自动探测 QIO）。

如果使用 esptool 5，可运行：

```sh
python -m esptool --chip esp32s3 --port /dev/cu.usbserial-10 --baud 460800 write-flash 0x0 baozi-five-wake-horizontal-idle-clean-full.bin
```

串口名以实际连接为准。完整镜像会覆盖 NVS 配置区域，烧录后可能需要重新配网、激活。
本次只读取了开发板信息，没有执行烧录。

## 验证

- 实读芯片：ESP32-S3 revision v0.2，16 MB Flash，8 MB PSRAM。
- 项目自带 110 项主机测试全部通过。
- 使用实际 LVGL 9.5.0 和修改后的字幕代码进行主机测试：短中文居中静止、长中文横向往返、换行转单行、长句切换短句、空消息隐藏，均通过。新增待机隐藏、时钟/通知更新不重新显示、离开待机恢复测试也通过。
- 固件编译、链接、分区大小检查通过；应用大小 2,699,344 字节，应用分区尚余约 35%。
- 引导程序和应用的 XOR / SHA-256 校验、分区表 MD5 校验通过。
- 新固件尚未在开发板上烧录验证屏幕、音频与网络行为。

修改源码见同目录的源码压缩包；关键补丁为 `subtitle-scroll.patch`，实际编译配置为 `sdkconfig.baozi`。
在已安装 ESP-IDF v6.1 的环境中，将源码解压至纯英文路径，执行：

```sh
python scripts/build.py bread-compact-wifi-lcd -c baozi.json --name bread-compact-wifi-lcd-baozi --language zh-CN
```

产物为 `build/merged-binary.bin`。
